# Stocat web

Use Vite+ to run the React application. TanStack Router generates routes from `src/routes`.

```sh
vp install
vp dev
```

Run these commands from `web` to check changes:

```sh
vp run build
vp check
vp test run
```

The build generates `src/routeTree.gen.ts` before TypeScript checks the application. Commit this file after route changes.
Do not edit this file manually.

## API client

Orval generates TanStack Query hooks from `../api/openapi.yaml` into `src/api/generated`.
Run `make generate-client` from the repository root after API changes.
This command writes the OpenAPI document and then runs `vp run generate:api`.
Commit the generated files. Do not edit them manually.

Requests go to `/api`. In development, Vite sends `/api` requests to the Go server on port 8080 and removes the prefix.
Use the same rule on the production host.
Failed requests throw `ApiError`. It contains the HTTP status and the problem details.

Add pages in `src/routes`. Group related routes in folders.
A folder name that starts with `_` adds a layout. It does not change the URL.

- `__root.tsx` loads the current user. It provides the theme and auth contexts.
- `_auth` contains the sign-in and registration pages. It sends signed-in users to `/`.
- `_app` contains the pages that require a session. It adds the site header and sends guests to sign in.
- `_app/settings/sessions.tsx` lists the sessions of the user. It revokes one session or all other sessions.

`parseUserAgent()` in `src/lib/user-agent.ts` uses Bowser to get the browser, operating system, and device type.

Read the user with `useAuth()`. Build forms with `useAppForm()` from `src/components/form.tsx`.
The router tools load only during development.

The production build writes files to `dist`. Configure the host to serve `index.html` for unknown application paths.
