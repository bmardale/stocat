# Stocat web

Use Vite+ to run the React application. TanStack Router generates routes from `src/routes`.

```sh
vp install
vp dev
```

Run these commands from `web` to check changes:

```sh
vp run build
vp check
vp test run
```

The build generates `src/routeTree.gen.ts` before TypeScript checks the application. Commit this file after route changes.
Do not edit this file manually.

Add pages in `src/routes`. Use `src/routes/__root.tsx` for the shared layout.
The router tools load only during development.

The production build writes files to `dist`. Configure the host to serve `index.html` for unknown application paths.
